ЖУРНАЛ ПРОВЕДЕНИЯ РАБОТ — APK ДЛЯ ANDROID

1. Распакуйте этот ZIP-архив на компьютере.
2. В репозитории https://github.com/koreevm64-hue/journal-rabot нажмите Add file -> Upload files.
3. Перетащите в загрузку файлы и папки ИЗ распакованного архива:
   .github, android-app, settings.gradle, build.gradle, gradle.properties.
   ВНИМАНИЕ: сохраняйте вложенные папки, особенно .github/workflows/build-apk.yml.
   Файл ИНСТРУКЦИЯ.txt загружать необязательно.
4. Нажмите Commit changes.
5. Откройте вкладку Actions в репозитории GitHub.
6. Найдите workflow «Собрать APK журнала работ» (может запуститься сам).
7. Если сборка не началась, нажмите Run workflow -> Run workflow.
8. После успешного завершения откройте запуск и скачайте артефакт Journal-Rabot-Android-APK.
9. Распакуйте скачанный ZIP: внутри будет app-debug.apk.
10. Передайте app-debug.apk через MAX и установите его на Android.

Приложение является оболочкой для сайта журнала.
Оно открывает онлайн-журнал через браузерные технологии Android.
Для первого запуска и синхронизации кода сайта требуется интернет.
Записи в текущей версии не имеют общей серверной базы.
Голосовой ввод зависит от браузера и разрешений на микрофон.

Важное замечание: это тестовая debug-сборка, подписанная GitHub Actions.
При сборке APK заново в другом запуске подпись может измениться,
и тогда старую версию нужно будет удалить перед установкой новой.
